# 🌿 GreenLeaf Plant Shop

A responsive, single-page website for a fictional small business that sells indoor plants, succulents, and plant-care kits. The website helps customers explore products, learn about the business, and send inquiries through a contact form.

## 📌 Project Information

- **Project Name:** GreenLeaf Plant Shop
- **Project Type:** Small Business Website
- **Purpose:** To promote plant products and provide customers with an easy way to contact the business.
- **Technologies:** HTML5, Tailwind CSS, JavaScript, GSAP, and ScrollTrigger

## 🎯 Objectives

- Create a responsive and user-friendly business website.
- Display plant products and their sample prices.
- Implement a working dark-mode toggle.
- Add animations using GSAP and ScrollTrigger.
- Provide a contact form with required fields.
- Practice using Git and GitHub for version control.

## 📄 Website Sections

### 1. Hero Section
Introduces GreenLeaf Plant Shop with a tagline, product button, and contact button.

### 2. About Section
Describes the business and highlights its focus on quality plants, beginner-friendly care, and greener living.

### 3. Products Section
Displays three product categories:
- Indoor Plants
- Succulents
- Plant Care Kits

### 4. Contact Section
Contains a form for the customer's name, email, and message.

### 5. Footer
Displays the business name and copyright information.

## 🛠️ Technologies Used

- **HTML5** — Provides the website structure and semantic elements.
- **Tailwind CSS v4** — Styles the website and supports responsive layouts.
- **JavaScript** — Handles dark mode and contact form interactions.
- **GSAP** — Creates the page-load introduction and animations.
- **ScrollTrigger** — Animates sections while scrolling and controls the progress bar.
- **Git and GitHub** — Used for version control and project submission.

## 🎨 Design System

### Color Palette: 60-30-10 Rule

| Percentage | Color | Hex Code | Purpose |
|---|---|---|---|
| 60% | Cream / Light Background | `#FFFBEB` | Main page background and open space |
| 30% | Leaf Green | `#166534` | Headings, buttons, and branding |
| 10% | Earth Brown | `#854D0E` | Small accents and supporting text |

Additional colors:
- **Sage Green:** `#DCFCE7`
- **Dark Background:** `#030712`
- **White:** `#FFFFFF`

The dark-mode theme uses dark gray and black backgrounds with green accents.

### Design Style

**Nature-Inspired Minimalism**

The design uses a clean layout, natural colors, readable typography, rounded product cards, and plant photography to create a calm and welcoming shopping experience.

## ✨ Features

- Responsive layout for mobile, tablet, and desktop.
- Dark-mode toggle.
- Animated hero section using a GSAP timeline.
- Replay Intro button to replay the hero animation.
- Scroll-triggered reveal animations.
- Scroll progress bar.
- Reduced-motion support for accessibility.
- Product cards with descriptions and sample prices.
- Contact form with labels and required fields.
- Reusable Tailwind component classes.

## 🚀 How to Run the Project

1. Download or clone the project repository.
2. Open the project folder in Visual Studio Code.
3. Make sure `index.html` and `script.js` are in the same folder.
4. Open `index.html` in your browser, or use the Live Server extension.
5. Test the navigation, dark-mode toggle, replay button, scrolling animations, and contact form.

An internet connection is required to load the Tailwind CSS, GSAP, ScrollTrigger, and external plant images.

## 🎬 Animation Details

- **Page-load timeline:** Animates the hero heading, paragraph, buttons, and navigation links.
- **Replay interaction:** Restarts the hero animation when the Replay Intro button is clicked.
- **Scroll reveals:** Reveals individual content sections as they enter the viewport.
- **Scroll progress:** Updates the progress bar according to page scrolling.
- **Accessibility:** Respects the visitor's reduced-motion preference.

## 📦 Limitations

This is a front-end demonstration project. Product prices are examples, and the contact form does not send actual emails or store messages in a database.
